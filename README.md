# versionControl-test

A demo repository for practicing Git and GitHub workflows — branching strategies, pull requests, code reviews, and squash merges.

## Getting Started

### Prerequisites

- [Git](https://git-scm.com/) installed locally
- A GitHub account with collaborator access to this repo

### Setup

```bash
# Clone the repository
git clone https://github.com/priyanshu-singh-sengar/versionControl-test.git
cd versionControl-test

# Create a feature branch
git checkout -b feature/your-feature-name
```

## Usage

1. Pick an open issue from the [Issues](https://github.com/priyanshu-singh-sengar/versionControl-test/issues) tab.
2. Create a feature branch (`feature/<short-description>`).
3. Make your changes and commit with clear messages.
4. Open a Pull Request targeting `main` and link it to the issue.
5. After review approval, merge using **squash merge** to keep history clean.
